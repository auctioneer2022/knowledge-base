## 评定口径说明

| 维度 | 等级定义 |
|------|----------|
| **成熟度** | 成熟=内容完备可直接作业且经交叉核对 / 稳定=功能完整、经测试或与成熟内容对应 / 可用=已充实具备实务示例但深度低于成熟层 / 原型=仅框架占位（本轮盘点已无此级） |
| **复用性** | 高=跨行业跨业务通用 / 中=特定场景或行业 / 低=单一用途 |
| **业务价值** | 高=一线高频刚需 / 中高=专项常用 / 中=低频参考 |
| **综合评定** | A+=旗舰（优先深度开发）/ A=核心 / B+=重要 / B=一般（待观察提升） |
| **智能工具情况** | ✅已代码化=已有配套可执行工具 / 可代码化=公式/算法齐备待封装 / 知识型=以检索参考为主 |

## 四、备注：分类与归属说明

1. **文件命名不统一**：06-IT审计、07-舞弊审计、08-内控评价共 6 个文件的**文件名未带 MTH 编号**（如 `IT审计基本方法.md`），但 frontmatter 中均有正式编号（MTH-06-001 ~ MTH-08-002），本清单统一按 frontmatter 编号收录。建议后续将文件名规范为 `MTH-XX-XXX-名称.md` 格式，与其他子模块保持一致。

3. **双载体工具计数**：MTH-03-003（文档）与 TOOLS-VAL（代码）实为同一工具的两种载体，清单中分别列示，统计时注意避免重复计数。
4. **管理文档不纳入评级**：模块内两份审计报告（2026-07-25 模块审计、2026-07-30 代码审计）及本清单为管理文档，不属于工具，未参与评级。
