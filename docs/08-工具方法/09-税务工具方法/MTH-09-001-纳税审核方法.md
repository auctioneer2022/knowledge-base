# 纳税审核方法

纳税审核是涉税专业服务机构接受委托，依据税收法律法规和鉴证准则，对纳税申报事项的真实性、合法性和准确性实施审核并出具意见的专业服务。权威依据为《涉税鉴证业务指引（试行）》《税务师行业涉税专业服务规范基本指引（试行）》，以及国家税务总局《企业所得税汇算清缴纳税申报鉴证业务准则（试行）》（国税发〔2007〕，以下简称《准则》）。

## 一、审核程序框架

审核遵循"业务承接—证据收集—业务实施—业务记录—出具报告"流程（《准则》《涉税鉴证业务指引》）。承接阶段了解业务环境、评估风险、签订约定书；实施阶段以职业怀疑态度执行必要程序，获取充分、适当证据，对计划、程序、证据与结论作记录，以税法为准绳并体现重要性原则，提供合理保证。

## 二、收入审核方法

基本方法：评价收入内控是否一贯有效；编制收入明细表，复核并与报表、总账、明细账及申报表核对；了解合同执行与业务合理性；查明收入确认原则，关注会计与税法差异（《准则》"收入的审核"）。按结算方式（直接收款、预收、托收承付、委托代销、分期收款等）判断收入实现时点，防范虚记、压单或跨期；施截止性测试，审核决算日前后出库单与发票，识别跨年度收入。

## 三、成本费用与纳税调整

成本费用审核应评价内控、核对明细表、抽查大额收支配比性（《准则》"成本费用的审核"）。重点核查限额扣除（业务招待费、广告费、捐赠）是否超标，资产税务处理（折旧、摊销、损失扣除）是否合规，及优惠（研发加计扣除、高新）资格与留存资料。对税会差异，审查公允价值变动、资产减值、未实现融资收益等项目的纳税调整，确保《纳税调整项目明细表》（A105000）准确。

## 四、证据与质量控制

证据围绕企业基本情况、财会制度、内控制度、重大交易、纳税调整、优惠、弥补亏损、境外抵免等收集评价（《企业所得税汇算清缴纳税申报鉴证业务指引》）。涉税人员遵循独立、客观、公正及鉴证与代理不相容原则，实施复核监控，出具无保留、保留、无法表明意见或否定意见的鉴证报告，作为税务机关核查的重要参考。

## 五、分税种审核实务示例（配套计算工具）

本方法配套可复用计算工具 `docs/08-工具方法/tools/tax_tools.py`（纯 Python、仅标准库、统一返回 `ToolResult`），提供税负率测算、纳税调整、发票风险扫描、税务健康度评分等函数，覆盖一线高频审核环节。各函数均含参数校验，校验失败抛 `ToolValidationError`。

### 5.1 增值税税负率审核

增值税税负率 = 实缴增值税 ÷ 应税销售收入。将实际税负率与行业预警值比较，显著偏低提示隐匿收入或进项异常。

```python
from tools import tax_tools as tt
print(tt.assess_vat_burden(180, 12000, industry="制造业").value)  # 正常 / 关注 / 高风险
```

### 5.2 企业所得税纳税调整测算

业务招待费按发生额 60% 扣除且不超过收入 5‰；广告费一般不超收入 15%；福利费不超工资 14%；工会经费 2%；职工教育经费 8%；向非金融机构借款利息超过同期贷款利率部分调增。

```python
r = tt.calc_tax_adjustment(
    revenue=10000, wages=2000, entertainment=120, advertising=1800,
    welfare=320, union_fund=40, education_fund=180,
)
print(r.value, r.details["items"])  # 纳税调增合计 ≈ 430 及各项明细
```

### 5.3 税务健康度评分

综合增值税/所得税税负预警、发票风险与纳税调整比例，输出 0~100 健康度分数与等级（优/良/中/差），便于对多家被审单位排序跟踪。详见 `tax_tools.tax_health_score`。
