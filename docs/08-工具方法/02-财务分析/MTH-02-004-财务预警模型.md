# 财务预警模型

财务预警模型通过多重财务比率的加权组合，预测企业陷入财务困境或破产的概率。最具代表性的为 Altman (1968) 提出的 Z-Score 多元判别模型，以及在其基础上针对非上市公司、非制造业与中国市场改进的 Z'-Score、Z"-Score 与 F 分数模型。

## 一、Altman Z-Score 原始模型

Altman (1968) 以美国制造业上市公司为样本，建立五变量判别函数（系数已核实）：

```
Z = 1.2X₁ + 1.4X₂ + 3.3X₃ + 0.6X₄ + 1.0X₅
X₁ = 营运资本 / 总资产（(流动资产−流动负债)/总资产）
X₂ = 留存收益 / 总资产
X₃ = 息税前利润(EBIT) / 总资产
X₄ = 股东权益市场价值 / 负债账面价值总额
X₅ = 销售收入 / 总资产
```

临界值（Altman, 1968）：**Z > 2.99** 为安全区；**1.81 < Z < 2.99** 为灰色区（判断失误较大）；**Z < 1.81** 为困境区，破产概率高。该模型对破产前 1 年预测准确率约 95%，前 2 年约 72%。

## 二、修正模型（Z'-Score、Z"-Score）

针对非上市制造业企业，Altman (1983) 将 X₄ 改为"股东权益账面价值/负债总额"，提出 Z'-Score：

```
Z' = 0.717X₁ + 0.847X₂ + 3.107X₃ + 0.420X₄ + 0.998X₅
临界值：Z' > 2.90 安全；1.23 < Z' < 2.90 灰色；Z' < 1.23 困境
```

针对非制造业（及新兴市场私营公司），剔除资产周转类 X₅，提出 Z"-Score：

```
Z" = 6.56X₁ + 3.26X₂ + 6.72X₃ + 1.05X₄（X₄为权益账面价值/负债）
```

临界值（非制造业/新兴市场）：**Z" > 2.60** 安全；**1.10 < Z" < 2.60** 灰色；**Z" < 1.10** 困境。

> 注：含 X₅ 的 Z'-Score（私营制造业）临界值为 > 2.90 / 1.23（见第二节），二者不可混淆。

## 三、F 分数模型

周首华、杨济华等（1996）在 Z 模型基础上引入现金流量变量，建立适用于中国企业的 F 分数模型：

```
F = −0.1774 + 1.1091X₁ + 0.1074X₂ + 1.9271X₃ + 0.0302X₄ + 0.4961X₅
X₁=(流动资产−流动负债)/总资产；X₂=留存收益/总资产；
X₃=(税后净利润+折旧)/平均总负债；X₄=股东权益市场价值/总负债；
X₅=(税后净利润+利息+折旧)/平均总资产
```

临界点为 **0.0274**：F > 0.0274 预示持续经营，F < 0.0274 预示破产风险；0.0274±0.0775（即 −0.0501~0.1049）为不确定区，需进一步分析。

## 四、应用要点与局限

应用时应先判断企业类型（上市/非上市、制造业/非制造业），选用对应模型与临界值，并连续多期观察 Z/F 趋势而非单期值。局限：未考虑行业景气周期、系数需随经济环境调整、依赖会计数据时效性，且对金融机构适用性差，宜与现金流分析结合使用。

## 五、配套计算工具与行业阈值表

为便于一线直接使用，本方法已封装为可复用计算工具 `docs/08-工具方法/tools/financial_warning.py`（纯 Python、仅依赖标准库、统一返回 `ToolResult`）。主要接口：

- `calc_altman_z(...)`：原始 Z-Score（上市制造业）
- `calc_altman_z_private(...)`：Z'-Score（私营制造业）
- `calc_altman_z_nonmanufacturing(...)`：Z"-Score（非制造/新兴市场）
- `calc_f_score(...)`：F 分数（中国样本）
- `assess_warning(model, z)` / `assess_f_score(f, threshold)`：风险区间判定

各函数均含完整参数校验（如总资产须 >0、总负债非负），校验失败抛 `ToolValidationError`，业务预警写入 `warnings`。

### 5.1 行业阈值速查表

| 模型 | 适用对象 | 安全 | 灰色 | 危机 |
|------|----------|------|------|------|
| Z（原始） | 上市制造业 | >2.99 | 1.81~2.99 | <1.81 |
| Z'（私营） | 非上市制造业 | >2.90 | 1.23~2.90 | <1.23 |
| Z''（非制造） | 非制造/新兴市场 | >2.60 | 1.10~2.60 | <1.10 |

| F 分数 | 扩展样本应用 | >0.3346 | — | <0.3346 |

### 5.2 应用示例

某上市制造业企业（单位：万元）：营运资金 1,200、留存收益 800、EBIT 600、权益市值 5,000、总负债 3,000、销售收入 9,000、总资产 10,000。

```python
from tools import financial_warning as fw
r = fw.calc_altman_z(1200, 800, 600, 5000, 3000, 9000, 10000)
print(r.value, fw.assess_warning("original", r.value).value)
# 输出：2.354 灰色
```

Z≈2.35 处于灰色区，应结合多期趋势与现金流分析进一步判断，不宜单期下定论。
