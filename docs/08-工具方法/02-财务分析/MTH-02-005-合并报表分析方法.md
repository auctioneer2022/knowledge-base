# 合并报表分析方法

合并报表分析方法以 CAS 33《企业会计准则第 33 号——合并财务报表》为依据，围绕合并范围确定、内部交易抵销与特殊交易处理，分析集团整体财务状况、经营成果与现金流量。

## 一、合并范围的确定（控制为基础）

CAS 33 以"控制"为基础确定合并范围（第六条），控制指能决定另一企业财务和经营政策并据以获取利益的权力。母公司直接或间接拥有半数以上表决权，推定控制（第七条）；拥有半数或以下表决权但满足"协议控制、依章程决定财务经营政策、任免董事会多数成员、董事会占多数表决权"之一者，亦视为控制（第八条）。确定时尚应考虑可转换公司债券、认股权证等潜在表决权（第九条），母公司应将其全部子公司纳入合并范围（第十条）。

## 二、抵销分录的编制

合并报表以母、子公司个别报表为基础，抵销内部交易影响后由母公司编制（第十一条、第十五条）。核心抵销：①长期股权投资与母公司在子公司权益中所享份额抵销，差额列"商誉"并抵销减值准备；子公司持母公司股权视为库存股作权益减项（第十五条、第三十条）；②母子公司及子公司间债权债务与减值准备相互抵销；③内部购销形成的存货、固定资产、无形资产所含未实现内部销售损益抵销，相关折旧、摊销及减值准备中与之相关的部分亦抵销（第十九条、第三十条）。子公司权益中属少数股东部分以"少数股东权益"列示，其净损益以"少数股东损益"列示（第二十条、第三十一条）。

## 三、特殊交易分析

同一控制下合并增加的子公司，调整合并报表期初数并视同自最终控制方控制起一直存在；非同一控制下增加的子公司不调整期初数，仅纳入购买日至期末数据（第十七条、第三十二条）。处置子公司不调整期初数（第十八条、第三十三条）。抵销未实现内部损益致账面价值与计税基础产生暂时性差异的，确认递延所得税资产或负债并调整所得税费用（第三十条）。

## 四、分析应用

分析时先验证合并范围完整性（关注结构化主体、潜在表决权），再审视抵销充分性（尤指不动产、长期资产内部交易及顺流/逆流交易对少数股东损益的影响），结合少数股东权益、商誉减值与分部信息评估集团盈利质量与风险。

## 五、抵销分录示例（配套计算工具）

本方法配套可复用计算工具 `docs/08-工具方法/tools/consolidation.py`（纯 Python、仅标准库、统一返回 `ToolResult`），可结构化生成抵销分录，便于直接填制工作底稿。主要接口：`assess_consolidation_scope`、`build_equity_offset`、`build_intercompany_payable_receivable`、`build_intercompany_revenue_cost`、`build_unrealized_profit`。

### 5.1 长期股权投资与所有者权益抵销

母公司对子公司长期股权投资 800 万，子公司所有者权益 1,000 万，少数股东持股 20%。

```
借：子公司所有者权益        1,000
　贷：长期股权投资            800
　　　少数股东权益            200（=1,000×20%）
```

当长期股权投资 > 应享权益份额（1,000×80%=800）时，差额确认商誉；反之列示为廉价购买（负商誉）。

### 5.2 内部债权债务抵销

A 公司应收 B 公司 500 万、B 公司应付 A 公司 500 万，按较小额全额抵销：

```
借：应付账款  500 　贷：应收账款  500
```

余额不等提示未达账项或入账差异，需追加核查。

### 5.3 内部交易与未实现损益抵销

母公司售予子公司存货，收入 200 万、成本 140 万，子公司期末未售比例 50%，少数股东持股 20%。

```
未实现损益总额 = (200−140) × 50% = 30 万
归属母公司份额 = 30 × (1−20%) = 24 万
```

```python
from tools import consolidation as co
print(co.build_equity_offset(800, 1000, 0.2).value[0].credits)   # [('长期股权投资',800),('少数股东权益',200)]
print(co.build_unrealized_profit(200, 140, 0.5, 0.2).value)       # 24.0
```
