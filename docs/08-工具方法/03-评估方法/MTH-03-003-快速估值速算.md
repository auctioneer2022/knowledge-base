# 快速估值与贬值速算

本方法从《企业价值评估》（MTH-03-001）与《资产评估方法》（MTH-03-002）中抽取**最常用、可参数化计算**的片段，形成一组"输入数据→输出结果"的快速计算工具，用于一线初步估值、贬值测算与合理性校验。工具已封装为可复用 Python 模块 `docs/08-工具方法/tools/valuation.py`（纯标准库、统一返回 `ToolResult`），与 MTH-03-001/002 知识文档互为补充。

## 一、折现率类

### 1.1 CAPM 股权资本成本

`calc_capm(risk_free_rate, beta, market_risk_premium)`：Ke = 无风险利率 + β × 市场风险溢价。

### 1.2 WACC 加权平均资本成本

`calc_wacc(weight_equity, cost_equity, weight_debt, cost_debt, tax_rate)`：WACC = We·Ke + Wd·Kd·(1−T)。权重合计不为 1 时给出预警。

## 二、企业/资产价值类

### 2.1 DCF 企业自由现金流折现

`calc_dcf(free_cash_flows, discount_rate, terminal_value=0, terminal_growth=None, terminal_year=None)`：预测期各期 FCF 现值之和加终值现值。终值可由 Gordon 模型（给定 `terminal_growth`，须 < 折现率）或外部给定。

### 2.2 收益法（资本化）

`calc_income_approach(net_operating_income, capitalization_rate)`：V = 年净收益 ÷ 资本化率。

### 2.3 市场法（乘数）

`calc_market_approach(target_metric, multiplier)`：V = 财务指标 × 市场乘数（P/E、P/B、EV/EBITDA 等）。

### 2.4 成本法

`calc_cost_approach(replacement_cost, physical_depr, functional_depr, economic_depr)`：V = 重置成本 − 实体性 − 功能性 − 经济性贬值；不低于 0。

## 三、贬值速算类

| 函数 | 公式 | 用途 |
|------|------|------|
| `calc_physical_depreciation(rc, age, total_life)` | 贬值 = RC × 已用年限 / 总年限 | 实体性贬值（年限法） |
| `calc_functional_obsolescence(eac, r, n)` | 贬值 = 年超额成本 × 年金现值系数 | 功能性贬值 |
| `calc_economic_obsolescence(rc, ub, ua)` | 贬值 = RC × (1 − 现状利用率/满负荷利用率) | 经济性贬值 |

## 四、应用示例

```python
from tools import valuation as va

# 折现率
ke = va.calc_capm(0.03, 1.2, 0.05).value            # 0.09
wacc = va.calc_wacc(0.7, 0.09, 0.3, 0.05, 0.25).value

# 企业价值（DCF）
ev = va.calc_dcf([100, 120, 140, 160, 180], discount_rate=0.10,
                 terminal_growth=0.02).value

# 成本法评估
pv = va.calc_cost_approach(1000, 200, 50, 30).value  # 720

# 贬值速算
pd = va.calc_physical_depreciation(1000, 4, 10).value  # 400
```

## 五、使用边界

- 快速估值用于初步判断与交叉验证，重大交易应以完整评估程序（MTH-03-001/002）为准。
- 折现率、乘数、资本化率等关键参数须基于可比市场与专业判断确定，工具仅执行计算。
- 所有函数含参数校验：非负/正数约束、权重与税率区间、Gordon 模型 g<r 等，校验失败抛 `ToolValidationError`。
