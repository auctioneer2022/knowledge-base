## 说明

1. 管理会计应用指引与《管理会计基本指引》（财会〔2016〕10号）配套，共同构成管理会计指引体系。
2. 第305号、第406号于2025年9月4日由财会〔2025〕22号通知印发；第804号于2026年6月23日由财会〔2026〕9号通知印发。
3. 各指引目前均为"参照执行"，不属于强制执行的企业会计准则，但在单位管理会计工作中具有重要指导价值。
