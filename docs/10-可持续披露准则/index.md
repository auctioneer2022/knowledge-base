# 可持续披露准则

收录财政部会同有关部门制定的企业可持续披露准则体系文件，包括基本准则、具体准则（气候等）及其应用指南。该体系由财政部牵头，会同生态环境部、外交部、国家发展改革委、工业和信息化部、商务部、中国人民银行、国务院国资委、金融监管总局、中国证监会研究制定，旨在规范企业可持续发展信息披露，稳步推进我国可持续披露准则体系建设。

> 说明：现行体系以《企业可持续披露准则——基本准则（试行）》（财会〔2024〕17号）为统领，具体准则和应用指南在其框架下逐步出台。在实施范围及实施要求作出规定之前，目前由企业自愿实施。

## 说明

1. 《企业可持续披露准则——基本准则（试行）》（财会〔2024〕17号）为体系基础，本模块暂收录其应用指南；基本准则正文将视需要另行补充录入。
2. 第1号——气候（试行）于2025年12月19日由财政部等九部门联合印发，是体系下首份具体准则，涵盖治理、战略、风险和机遇管理、指标和目标四大核心要素及术语定义附录。
3. 各项文件目前"由企业自愿实施"，待国家统一规定实施范围及实施要求后转为强制披露。
