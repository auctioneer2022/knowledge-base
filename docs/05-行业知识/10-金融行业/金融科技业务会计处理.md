# 金融科技业务会计处理

## 1. 金融科技业务的收入确认
金融科技企业从事支付、助贷、技术服务等，其收入确认适用《企业会计准则第14号——收入》(财会〔2017〕22号)。支付机构向商户收取的交易手续费、向用户收取的提现费等，属于在某一时点履行的履约义务，于服务提供完成时按净额确认收入；为商户提供SaaS、风控等技术服务并按期收费的，通常属于在某一时段内履行的履约义务，按履约进度分期确认。涉及代收代付的资金不计入收入。

## 2. 助贷业务的收入与风险
助贷机构为金融机构推荐借款人并收取服务费，应判断其是主要责任人还是代理人：若仅提供引流、不承担信用风险，按净额确认助贷服务费；若实质上承担回购或担保义务，相关对价可能需结合担保会计处理。依据财会〔2017〕22号，应付客户对价(如对借款人的利息补贴、返现)应冲减交易价格。助贷收入应与实际提供的服务相匹配，避免将尚未实现的导流一次性确认。

## 3. 减值准备的预期信用损失模型
金融科技涉及的应收服务费、担保代偿款、发放贷款或垫款等，适用《企业会计准则第22号——金融工具确认和计量》(财会〔2017〕7号)的预期信用损失模型。企业应按三阶段法，考虑前瞻性信息，对以摊余成本计量的金融资产计提减值准备，信用减值损失计入当期损益。助贷业务若形成表内应收代偿款或坏账，应基于历史违约率、宏观情景进行估计并充分披露。
