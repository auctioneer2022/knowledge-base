# 股权激励会计处理

## 1. 适用准则与激励工具
高新技术企业对核心技术人员实施股权激励，应适用《企业会计准则第11号——股份支付》(财会〔2006〕3号)。该准则第二条规定，股份支付是为获取职工和其他方提供服务而授予权益工具或承担以权益工具为基础确定负债的交易，分为以权益结算和以现金结算两类。实务中高新技术企业常用限制性股票、股票期权两类权益结算工具。

## 2. 限制性股票与股票期权账务处理
以权益结算的股份支付，应按授予日权益工具公允价值计量。财会〔2006〕3号第五条、第六条规定，除立即可行权外，在等待期内每个资产负债表日，应以对可行权权益工具数量的最佳估计为基础，按授予日公允价值将当期取得的服务计入相关成本或费用，并增加资本公积；可行权日之后不再对已确认的成本费用和所有者权益总额进行调整。限制性股票通常设服务期或业绩条件，等待期内分期确认费用；股票期权同理按期权公允价值(可参照《企业会计准则第22号——金融工具确认和计量》确定)分摊。应用指南(财会〔2006〕18号)对集团内股份支付、回购股份授予等情形作了补充。

## 3. 递延所得税与披露
等待期内确认的股份支付费用形成会计利润与税法扣除时间的暂时性差异，应确认递延所得税资产。高新技术企业享受研发加计扣除的同时实施激励，需注意费用归集口径，避免重复或遗漏。年报中应披露各类股份支付的数量、公允价值确定方法、当期确认的费用及资本公积变动，确保符合财会〔2006〕3号披露要求。
