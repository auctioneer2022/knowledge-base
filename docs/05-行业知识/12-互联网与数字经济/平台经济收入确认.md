# 平台经济收入确认与分成会计处理

## 一、准则依据与适用情形

平台经济、共享经济模式下，平台企业撮合供需双方交易并收取佣金或参与收入分成，其收入确认适用《企业会计准则第14号——收入》（财会〔2017〕22号，以下简称CAS14）。当平台在交易中仅提供技术撮合、支付结算与信用担保，而由入驻商户或服务提供方向终端客户直接交付商品或服务时，需判断平台是以“主要责任人”还是“代理人”身份确认收入。财政部、国资委、银保监会、证监会《关于严格执行企业会计准则切实加强企业2020年年报工作的通知》（财会〔2021〕2号）进一步明确，应基于“控制权”判断采用总额法或净额法。

## 二、总额法（主要责任人）与净额法（代理人）的判断

CAS14第三十四条规定，企业向客户转让商品前拥有该商品控制权的，按已收或应收对价总额确认收入（总额法）；不拥有控制权的，按预期有权收取的佣金或手续费净额确认收入（净额法）。控制权判断依据CAS14对“取得商品控制权”的定义，即能够主导商品使用并从中获得几乎全部经济利益。平台若自主定价、承担存货风险与售后责任、可自主选用供应商，通常为主导方，应采用总额法；若仅按固定比例抽成、商品风险由商户承担，则为代理人，采用净额法。该判断直接影响收入规模与毛利率，应在会计政策中一贯运用并充分披露。

## 三、可变对价与分成、应付客户对价

平台与商户的分成常包含返佣、满减补贴、流量奖励等可变安排。CAS14第十六条规定，合同中存在可变对价的，应按期望值或最可能发生金额估计，且计入交易价格的可变对价金额不得超过在不确定性消除时“极可能不会”发生重大转回的金额，资产负债表日需重新估计。此外，平台向客户或商户支付的补贴、返利，属于CAS14第十九条“应付客户对价”的，应冲减交易价格并相应冲减收入（为取得可明确区分商品除外）。相关收入应按履约义务履行时点或时段确认，确保分成金额与履约进度相匹配。
