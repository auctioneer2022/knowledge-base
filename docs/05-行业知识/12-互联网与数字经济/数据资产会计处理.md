# 数据资产会计处理

## 一、准则依据与适用范围

依据财政部《企业数据资源相关会计处理暂行规定》（财会〔2023〕11号，2024年1月1日施行），企业数据资源会计处理适用现行企业会计准则，不改变现行确认计量要求。该规定适用于两类情形：一是企业按照企业会计准则确认为无形资产或存货的数据资源；二是企业合法拥有或控制、预期带来经济利益，但因不满足确认条件而未确认为资产的数据资源（相关披露适用）。数据资源不属于上述资产类别的，仍按原有规定处理。企业执行该规定应采用未来适用法，施行前已费用化的支出不再调整。

## 二、无形资产与存货的列报

企业内部使用的数据资源，符合《企业会计准则第6号——无形资产》（财会〔2006〕3号）定义与确认条件的，确认为无形资产，按成本初始计量，其中外购取得成本包括购买价款、相关税费及数据脱敏、清洗、标注、整合、分析、可视化等加工支出；研究开发支出区分研究阶段与开发阶段，开发阶段满足资本化条件的方可资本化。日常活动中持有、最终用于出售的数据资源，符合《企业会计准则第1号——存货》（财会〔2006〕3号）定义的，确认为存货。企业利用数据资源对客户服务的，应按《企业会计准则第14号——收入》（财会〔2017〕22号）确认相关收入。

## 三、披露要求

资产负债表列示方面，企业应在“存货”项目下增设“其中：数据资源”，反映确认为存货的数据资源期末账面价值；在“无形资产”项目下增设“其中：数据资源”；在“开发支出”项目下增设“其中：数据资源”，反映满足资本化条件的研发支出金额。附注披露上，应分类披露确认为无形资产、存货的数据资源相关信息，包括使用寿命估计、摊销方法、减值情况等；同时鼓励自愿披露数据资源应用场景、原始数据类型与规模、加工维护情况、应用与交易情况等，以提升会计信息有用性。
