# 电商业务会计处理

## 1. 网络零售收入确认
电商企业销售商品适用《企业会计准则第14号——收入》(财会〔2017〕22号)。网络零售一般为在某一时点履行的履约义务，企业在客户取得商品控制权(通常为发货后买家确认收货或系统自动确认、且主要风险报酬转移)时确认收入。寄售、平台代发等模式下，应判断企业是主要责任人(按总额确认收入)还是代理人(按净额确认手续费收入)；依据财会〔2017〕22号第三十四条，企业代第三方收取的款项不计入交易价格。

## 2. 销售退回的处理
电商普遍存在"七天无理由退货"。财会〔2017〕22号第三十二条要求，对于附有销售退回条款的销售，企业应在客户取得控制权时按预期有权收取的对价金额确认收入，按预期退回金额确认"预计负债——应付退货款"，并按退回商品成本扣除收回成本后的净额确认"应收退货成本"计入存货。每一资产负债表日应重新估计退货率并调整。

## 3. 平台佣金的核算
电商平台收取的开店费、技术服务费、交易佣金，对商家构成应付客户对价或合同取得/履约成本。佣金通常作为销售费用；一次性入驻费若与持续服务相关，按合同期分摊。商家支付给平台的推广费，依据财会〔2017〕22号第十九条，若为取得可明确区分商品或服务按采购处理，否则冲减交易价格。电商企业还应就刷单、红包等促销的会计处理保持审慎，确保收入真实、完整。
