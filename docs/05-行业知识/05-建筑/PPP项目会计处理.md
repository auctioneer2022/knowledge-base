# PPP项目会计处理

## 1. 适用解释与"双特征、双控制"
社会资本方对PPP项目合同的会计处理适用《企业会计准则解释第14号》(财会〔2021〕1号)。该解释规定，PPP项目合同须同时符合"双特征"——社会资本方代表政府方使用项目资产提供公共产品服务、并就提供的服务获得补偿；并符合"双控制"——政府方控制或管制服务类型、对象和价格，且合同终止时控制项目资产重大剩余权益。不同时符合的，按业务性质适用其他准则。

## 2. 三类资产模式的判断
根据财会〔2021〕1号，社会资本方提供建造服务应按《企业会计准则第14号——收入》判断主要责任人或代理人并确认合同资产；同时按合同对价摊至各单项履约义务。在运营期，应区分三种模式：(1) 金融资产模式——有权收取可确定金额的现金，确认为金融资产(应收款项或长期应收款)并按《企业会计准则第22号——金融工具确认和计量》计量；(2) 无形资产模式——向使用者收费且金额不确定，确认为无形资产，在运营期内摊销并确认运营收入；(3) 混合模式——部分可确定补偿、部分收费不确定，分别确认金融资产与无形资产。

## 3. 借款费用与列报
建造期间符合资本化条件的借款费用，对应无形资产部分的计入"PPP借款支出"并最终转入无形资产(财会〔2021〕1号)。相关合同资产在资产负债表根据预计变现期限列报于无形资产、合同资产或其他非流动资产。社会资本方应在附注按重要性披露各项PPP合同信息，或合并披露一组具有类似性质的PPP项目合同。
