# 预售资金监管会计处理

## 1. 预售资金监管的制度基础
《城市商品房预售管理办法》(建设部令第131号，2004年修正)第十一条规定，开发企业预售商品房所得款项应当用于有关的工程建设，商品房预售款监管的具体办法由房地产管理部门制定；上位法《中华人民共和国城市房地产管理法》第四十五条亦明确商品房预售所得款项必须用于有关的工程建设。2022年《住房和城乡建设部、人民银行、银保监会关于规范商品房预售资金监管的意见》(建房〔2022〕16号)进一步要求，市、县住建部门办理房屋交易合同网签备案时，商品房预售资金应当按要求同步存入监管账户。

## 2. 预售款专户与收入确认
预售资金应存入商业银行设立的监管专用账户，企业不得擅自挪用。会计上，预售阶段收取的房款在房屋达到收入确认条件前，通常作为"预收账款"核算，不构成当期收入。根据《企业会计准则第14号——收入》(财会〔2017〕22号)第四条，企业应当在客户取得相关商品控制权时确认收入；商品房预售属于在某一时点履行的履约义务，应于房屋竣工交付、客户取得控制权时结转收入，并相应结转变动成本。监管账户内资金虽由企业控制但受用途限制，需在附注中披露受限情况。

## 3. 资金流审计要点
审计应重点关注：(1) 预售款是否全额、及时进入监管账户，有无账外账；(2) 监管资金拨付是否与工程进度匹配，是否实际用于工程建设；(3) 收入确认时点是否与交付一致，有无提前确认；(4) 受限资金披露是否充分。依据建房〔2022〕16号，监管资金拨付应与施工进度挂钩，审计需核对监理确认的工程量与用款计划，防范挪用风险。
