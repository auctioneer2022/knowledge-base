# 限定性资产会计处理

## 1. 限定性净资产的定义
民间非营利组织(民非组织)适用《民间非营利组织会计制度》(财会〔2024〕25号)。该制度第五十六条规定，净资产应按是否受到限制分为限定性净资产和非限定性净资产。若资产或其产生的经济利益(如投资收益、利息)的使用受到资产提供者或国家有关法律、行政法规设置的时间限制或(和)用途限制，由此形成的净资产即为限定性净资产；制度所称时间限制指要求在收到后特定期限内或特定日期之后使用，或设置永久限制；用途限制指要求用于某一特定用途。董事会等内部管理作出的限制不属于本制度界定的限定性净资产。

## 2. 限定性资产的取得与核算
接受附条件捐赠、政府限定用途补助时，取得的相关资产确认为限定性资产，对应贷记"捐赠收入——限定性收入"或"政府补助收入——限定性收入"。根据《〈民间非营利组织会计制度〉若干问题的解释》(财会〔2020〕9号)，资产提供者要求在特定日期之后将资产用于特定用途的，应在该日期起按资产剩余使用年限分期将限定性净资产转为非限定性净资产。因国家法律、行政法规撤销限制的，在撤销时全额转入非限定性净资产；对以前未受限资产新增限制的，应将非限定性净资产转为限定性净资产。

## 3. 2024年修订的简化处理
财会〔2024〕25号修订后，简化了限定性净资产重分类：各项收入费用区分限定性与非限定性核算，期末将限定性收入和费用直接结转至限定性净资产，取消使用时的重分类要求。提取风险准备金、专项资金的，按实际提取额从非限定性净资产转入限定性净资产。期末应在业务活动表及附注中分项列示限定性与非限定性净资产变动。
