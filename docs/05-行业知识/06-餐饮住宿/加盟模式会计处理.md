# 加盟模式会计处理

## 1. 加盟业务的性质与适用准则
餐饮住宿企业以特许经营方式扩张时，加盟商支付初始加盟费、持续特许权使用费(含管理费、系统使用费等)。此类交易属于向客户转让知识产权的许可，适用《企业会计准则第14号——收入》(财会〔2017〕22号)，并参照该准则关于"授予知识产权许可"的规定判断收入确认时点。

## 2. 初始加盟费的收入确认
初始加盟费通常对应品牌授权、选址评估、开业培训等履约义务。依据财会〔2017〕22号，企业应识别合同中的单项履约义务，将交易价格按单独售价相对比例分摊。若初始服务在开业前一次性提供且客户已取得控制权，可在服务完成时一次性确认收入；若授权构成持续性权利(如商标在整个授权期可用)，则应按授权期分期确认。企业不得仅以收款时点确认收入。

## 3. 持续特许权使用费
按营业额一定比例收取的管理费、特许权使用费，属于可变对价。财会〔2017〕22号第十六条规定，企业应按期望值或最可能发生金额确定可变对价最佳估计，且计入交易价格的不超过不确定性消除时累计已确认收入极可能不会发生重大转回的金额；通常按加盟商实际营业额的计量周期(月/季)分期确认。一次性收取的年度系统维护费，按服务期分摊。加盟模式下还应区分直营与加盟，避免将加盟收入误列为自营收入。
