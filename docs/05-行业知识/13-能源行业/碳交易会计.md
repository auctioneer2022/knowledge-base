# 碳交易会计

## 一、适用范围与确认计量原则

依据财政部《碳排放权交易有关会计处理暂行规定》（财会〔2019〕22号，2020年1月1日施行），本规定适用于按照《碳排放权交易管理暂行办法》等规定开展碳排放权交易业务的重点排放单位中的相关企业（重点排放企业）。其会计处理遵循“取得方式决定计量”原则：通过购入方式取得碳排放配额的，在购买日确认为“碳排放权资产”并按成本计量；通过政府免费分配等无偿方式取得的碳排放配额，不作账务处理。重点排放企业开展碳排放权交易均应按本规定进行会计处理。

## 二、账务处理

（一）购入配额：按购买日实际支付或应付价款（含交易手续费等税费），借记“碳排放权资产”（科目编号1489），贷记“银行存款”“其他应付款”等。无偿取得不作账务处理的，应在备查簿登记。

（二）履约使用：使用购入配额履约的，按账面余额借记“营业外支出”，贷记“碳排放权资产”；使用无偿取得配额履约的，不作账务处理。

（三）出售配额：出售购入配额的，按实收价款借记“银行存款”等，按账面余额贷记“碳排放权资产”，差额计入“营业外收入”或“营业外支出”；出售无偿取得配额的，按实收价款贷记“营业外收入”。

（四）自愿注销：注销购入配额的，按账面余额借记“营业外支出”，贷记“碳排放权资产”；注销无偿取得配额的不作账务处理。

## 三、列报与披露

“碳排放权资产”科目借方余额在资产负债表“其他流动资产”项目列示。重点排放企业应当在财务报表附注中披露碳排放权交易相关信息，包括配额取得方式、数量、金额及使用情况等，以反映碳排放权资产对企业财务状况的影响。执行中应注意区分配额来源，准确核算营业外收支，并妥善保存无偿配额的备查登记。
