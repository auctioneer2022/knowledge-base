# 资产弃置义务会计

## 一、准则依据与概念

资产弃置义务（Asset Retirement Obligation，ARO）指企业在取得或建造固定资产（如油气井、核电站、矿区设施）时承担的、于资产报废或矿区废弃时履行拆移、清理、恢复环境等现时义务。我国相关规定主要包括《企业会计准则第13号——或有事项》（财会〔2006〕3号）、《企业会计准则第27号——石油天然气开采》（财会〔2006〕3号）第二十三条，以及《企业会计准则第4号——固定资产》应用指南（财会〔2006〕18号）关于弃置费用的规范。国际可比口径为《国际会计准则第37号——准备、或有负债和或有资产》（IAS 37）。

## 二、现值计量与初始确认

当弃置义务满足CAS13第四条预计负债确认条件（现时义务、很可能导致经济利益流出、金额能可靠计量）时，应确认为预计负债。CAS13第六条及应用指南明确，未来应支付金额与其现值相差较大的（如油气井、核电站弃置费用），应按未来现金流出的现值确定最佳估计数，考虑货币时间价值与风险。初始计量时，弃置费用现值应计入相关固定资产（或井及相关设施）成本，同时确认同等金额的预计负债：借记“固定资产/油气资产”，贷记“预计负债——弃置义务”。CAS27第二十三条规定，企业承担的矿区废弃处置义务满足预计负债确认条件的，应确认为预计负债并相应增加井及相关设施的账面价值。

## 三、后续计量与披露

资产负债表日，预计负债应按摊余成本计量，每期按折现率计提利息费用，增加预计负债账面余额并计入财务费用；固定资产弃置成本按相应折旧政策计提折旧。实际发生弃置支出时，转销预计负债。企业应在附注中披露预计负债的种类、期初与期末余额、本期变动、折现率等关键假设。对油气资产，还应按CAS27要求披露矿区废弃相关义务信息，确保环境恢复责任在财务报告中得到恰当反映。
