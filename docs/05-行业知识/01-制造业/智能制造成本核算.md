# 智能制造成本核算

## 1. 智能制造对成本核算的挑战
智能制造以柔性生产线、个性化定制和海量工序切换为特征，传统以产品品种、批次或生产步骤为对象的品种法、分批法，难以准确归集频繁切换所产生的间接费用。根据《企业产品成本核算制度(试行)》(财会〔2013〕17号)第九条，制造企业一般按照产品品种、批次订单或生产步骤确定成本核算对象；但该制度第三十六条同时明确，制造企业可以根据自身经营管理特点和条件，利用现代信息技术，采用作业成本法对不能直接归属于成本核算对象的成本进行归集和分配。这为智能工厂引入作业成本法(ABC)提供了制度依据。

## 2. 作业成本法在智能工厂的应用
在智能工厂中，MES、ERP 与物联网设备实时采集机器工时、能耗、换线次数等数据，使"资源—作业—产品"的因果驱动关系得以量化。企业应将自动化设备折旧、在线检测、厂内物流等间接费用先归集到"设备运行""质量检验""订单换线"等作业中心，再按作业动因(如机器工时、检验次数、换线次数)分配至具体产品。财会〔2013〕17号第三十六条对多维度、多层次核算的支持，使这种精细化分摊具备合规性。

## 3. 核算要点与披露
(1) 合理划分作业中心与动因，避免动因选择随意导致成本扭曲；(2) 与《企业会计准则第1号——存货》(财会〔2006〕3号)衔接，将合理分配的生产费用计入存货成本；(3) 在成本报表中按产品维度、工序维度、设备维度输出信息，满足事前、事中、事后全过程管控要求(财会〔2013〕17号第四条)。智能制造成本核算的核心，是在合规前提下借助信息技术提升间接费用分摊的准确性与产品成本可比性。
