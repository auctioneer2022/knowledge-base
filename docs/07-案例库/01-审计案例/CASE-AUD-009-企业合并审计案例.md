# 企业合并审计案例

## 案情概述

方正电机因收购上海海能汽车电子有限公司（以下简称"上海海能"）形成商誉。经另案查明，方正电机2019年至2022年年度报告因不恰当地扩大上海海能商誉相关资产组范围（将业务方向明显不同的方正电机越南公司纳入资产组），导致商誉减值准备计提金额不准确。结合"三包费"会计估计影响，2019年至2022年方正电机应补充确认商誉减值准备金额分别为1,733,842.21元、32,906,876.18元、14,717,695.60元、-84,412,115.24元，占当期披露利润总额绝对值的比例分别为9.29%、5.08%、176.72%、-25.26%，相关财务数据纳入合并报表后导致年报存在虚假记载。

## 审计发现

致同会计师事务所（特殊普通合伙）在审计中未勤勉尽责。2019年审计时，致同所已明知越南方正不属于最初收购上海海能形成商誉的资产组，且二者业务方向明显不同，虽通过访谈、书面说明获取了管理层考虑因素，但未据以设计并实施恰当审计程序，未充分评估管理层信息与实际情况是否相符，未获取充分、适当审计证据。2020年、2021年、2022年审计中，致同所在总体策略中虽已考虑商誉减值涉及重大管理层判断，但底稿中未见对资产组划分合理性设计并实施充分复核程序，未充分关注管理层此前提供信息的后续进展，未就资产组范围及商誉减值会计估计获取充分、适当证据，违反了《中国注册会计师审计准则第1321号——审计会计估计》等规定。

## 处理结果

中国证监会浙江监管局出具《行政处罚决定书》〔2024〕47号，对致同所及签字注册会计师高飞、曾涛、陈颖、戴思敏在方正电机2019—2022年审计中的未勤勉尽责行为作出行政处罚（具体罚没金额以处罚决定书为准）。

## 要点分析

企业合并形成的商誉后续减值测试，核心在于资产组的恰当划分。审计师应独立判断管理层确定的商誉相关资产组是否合理，关注并购标的与后续纳入主体在业务、现金流上的协同性，不能仅以管理层说明代替审计证据。资产组范围的随意扩大或缩小将直接扭曲商誉减值金额，是近年证券审计处罚的高频问题。
