# 康美药业财务造假审计案例

## 案情概述

康美药业股份有限公司（600518）系A股医药上市公司。经查，2016年至2018年，康美药业通过虚开和篡改增值税发票、伪造银行单据等方式，累计虚增货币资金886.8亿元（部分报道四舍五入为887亿元），累计虚增营业收入291.28亿元（约275亿元），累计虚增营业利润41.01亿元（约39亿元），同时存在违规占用上市公司资金、未按规定披露关联交易等问题，创下A股史上财务造假金额最高纪录。广东正中珠江会计师事务所（特殊普通合伙）为其提供年报审计并出具无保留意见审计报告。

## 审计发现

正中珠江在审计中未实施基本的审计程序，严重违反审计准则和职业道德守则：对银行存款未保持合理怀疑，银行函证程序流于形式，未能发现金融机构提供的虚假证明文件；未充分执行收入、关联方资金占用等审计程序，导致巨额财务造假未被审计发现。正中珠江出具的2016—2018年审计报告存在虚假记载，影响极其恶劣。

## 处理结果

2020年5月，中国证监会对康美药业作出行政处罚。2021年11月12日，广州市中级人民法院适用特别代表人诉讼程序作出一审判决：康美药业向52,037名投资者赔偿投资损失约24.59亿元；原董事长马兴田及5名直接责任人员、正中珠江及直接责任人员承担全部连带赔偿责任；13名相关责任人员按过错程度承担部分连带赔偿责任；5名独立董事分别在投资者损失5%、10%范围内承担连带赔偿责任（对应金额约1.23亿至2.46亿元）。2021年11月17日，佛山市中级人民法院以操纵证券市场罪、违规披露不披露重要信息罪、单位行贿罪数罪并罚，判处马兴田有期徒刑12年，并处罚金120万元。2026年7月，广州中院在追偿权纠纷一审中判令马兴田夫妇赔偿康美药业13.96亿元，正中珠江在1.41亿元范围内承担补充清偿责任。

## 要点分析

本案是新《证券法》实施后首例证券纠纷特别代表人诉讼，确立了"看门人"机构与直接责任人员承担连带赔偿责任的标杆。审计机构对银行存款、收入、关联方等高风险领域必须保持职业怀疑、严格执行函证等核心程序；独立董事亦因签字确认财报真实性承担比例连带责任，直接推动了A股独立董事履职生态的改变。
