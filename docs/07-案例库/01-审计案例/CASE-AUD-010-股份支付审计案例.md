# 股份支付审计案例

## 案情概述

星网锐捷控股子公司锐捷网络股份有限公司在2017年度至2021年度对股份支付的会计处理，未按服务年限分期计提分摊，而是一次性计入了当期损益，导致星网锐捷2017年度至2021年度财务报表及附注中资本公积、未分配利润、利润总额、归属于母公司股东的净利润等会计科目出现错报。其中，2017年度、2019年度至2021年度错报金额超过了华兴会计师事务所（特殊普通合伙）执行的审计重要性水平。

## 审计发现

华兴所执行星网锐捷财务报表审计项目时，未对股份支付相关会计处理保持职业怀疑、未作适当职业判断，直接对星网锐捷关于股份支付的会计处理予以认定。审计师本应关注股份支付准则关于"等待期内分期确认"的基本要求，核实授予日、等待期、可行权数量最佳估计等关键参数，但华兴所未就一次性计入损益的异常处理获取充分、适当的审计证据，违反了《中国注册会计师审计准则第1101号——注册会计师的总体目标和审计工作的基本要求》关于职业怀疑和职业判断的规定。相关年度审计报告中，林文锋、陈航晖为2017年度签字注册会计师，林海、陈航晖为2018—2021年度签字注册会计师。

## 处理结果

上述行为违反了《上市公司信息披露管理办法》相关规定。依据该办法，福建证监局决定对华兴所及注册会计师林文锋、林海、陈航晖采取监管谈话的行政监管措施，要求于2024年1月5日接受监管谈话，并在收到决定书之日起30日内提交书面整改报告。

## 要点分析

股份支付涉及等待期、行权条件、可行权数量估计等大量管理层判断，是财务错报的高风险领域。审计师应保持职业怀疑，重点核查：授予协议约定的服务期限、业绩考核条件是否达成、可行权权益工具数量的最佳估计是否合理。对一次性计入损益等与准则明显背离的处理，必须追查商业实质与会计依据，不能以管理层主张替代独立判断。
