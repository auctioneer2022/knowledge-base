# 金融工具审计案例

## 案情概述

立信中联会计师事务所（特殊普通合伙）系中兴天恒能源科技（北京）股份公司（以下简称"中天能源"）2019年度、2020年度财务报表审计机构，对上述两期财务报表均出具了带强调事项段的无保留意见审计报告。经另案查明，中天能源2019年年报少计提担保相关预计负债0.72亿元、虚增利润0.72亿元；2020年年报少计提担保预计负债0.64亿元、虚增利润0.64亿元，同时少计提对湖北九头风、加拿大优势两家企业应收款项坏账准备分别为1.32亿元、1.92亿元，相应虚增2020年利润3.24亿元。上述应收款项属于典型的金融资产，其减值计提是否充分直接关系财务报表真实公允。

## 审计发现

立信中联在审计中未勤勉尽责，出具的审计报告存在虚假记载。一是针对担保预计负债，实质性程序存在重大缺陷，未发现中天能源会计准则适用错误，未获取预计负债计提比例的充分、适当审计证据。二是针对应收款项减值准备（金融资产减值），实质性程序存在重大缺陷：九头风2.64亿元、加拿大优势3.84亿元款项不计提减值的审计结论缺乏充分、适当证据支持；未对抵债标的公司股权价值《预评估报告》的可靠性保持应有职业怀疑，复核审计程序受限。该所行为违反了《中国注册会计师审计准则第1321号——审计会计估计》等规定。

## 处理结果

依据《证券法》第二百一十三条第三款，北京证监局出具《行政处罚决定书》〔2023〕8号，对立信中联会计师事务所（特殊普通合伙）责令改正，没收业务收入2,264,150.94元，并处以2,264,150.94元罚款；对签字注册会计师高凯、周赫然给予警告，并分别处以30万元罚款。

## 要点分析

金融资产减值是审计中的高风险领域，注册会计师应充分关注单项重大应收款项的可收回性，独立评估管理层减值测试的假设与依据，对以资抵债等非常规交易的标的价值保持职业怀疑。直接依赖企业提供的评估报告或预评估报告而缺乏独立复核，是审计失败的常见诱因。本案体现了监管对金融资产减值审计"未勤勉尽责"认定的明确尺度。
