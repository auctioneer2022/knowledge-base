# 会计师事务所证券虚假陈述民事赔偿案例

## 案情概述

2014年11月，昌某股份公司（挂牌公司）在全国中小企业股份转让系统发布《公开转让说明书》，主办券商为东某证券公司，会计师事务所为大某会计师事务所。2014年至2016年，昌某股份虚构放贷业务，将款项转入控股股东控制的公司，形成关联方资金占用合计18,950万元（其中8,750万元到期未清偿）；2015年至2016年未经决策审批为实际控制人控制公司对外借款提供担保合计16笔、累计7,730万元，且未按规定披露。大某所执行的该公司2014年、2015年年报审计项目，存在风险评估、函证、控制测试程序执行不到位，底稿编制内容与实际不符等情形，江苏证监局对其采取监管谈话措施。投资者因信息披露不实遭受损失，起诉昌某股份及东某证券、大某会计师事务所。

## 争议焦点

本案争议焦点在于证券服务机构责任边界：一是挂牌公司欺诈发行、财务造假情形下，审计机构与主办券商的过错及赔偿责任如何认定；二是审计机构未勤勉尽责（底稿直接使用模板、函证与风险评估程序缺失）是否构成重大过失并应承担相应比例的连带赔偿责任；三是各中介机构责任份额如何划分。

## 裁判要旨

江苏省高级人民法院、南京市中级人民法院经审理认为，昌某股份未按规定披露关联方资金占用及对外担保，东某证券、大某会计师事务所对不实信息披露文件的发布存在过失，均应承担相应赔偿责任。大某会计师事务所除风险评估、函证、控制测试程序不到位外，编制底稿直接使用模板原内容、未根据公司实际情况修改，出具报告未充分勤勉尽责，存在过错；东某证券未对可能涉嫌关联交易的业务重点关注、充分尽职调查与审慎核查，亦存在过错。判决：昌某股份公司赔偿投资者全部损失，大某会计师事务所在10%范围内、东某证券在5%范围内承担连带赔偿责任。

## 要点分析

本案系最高人民法院发布的财务造假典型案例，明确证券服务机构"严重违反注意义务、发布不实文件存在过失的，应承担过错赔偿责任"，而非一概 full 连带责任。审计机构应归位尽责，特别警惕底稿模板化、函证与风险评估程序空转等"形式合规、实质失职"问题；责任比例与过错程度相匹配，体现了司法对中介机构"看门人"责任的精细化认定。
