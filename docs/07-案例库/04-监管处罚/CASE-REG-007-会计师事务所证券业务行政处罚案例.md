# 会计师事务所证券业务行政处罚案例

## 案情概述

立信会计师事务所（特殊普通合伙）系日海智能科技股份有限公司（以下简称"日海智能"）2018年、2019年年度财务报表审计机构，并出具了标准无保留意见的审计报告。经另案查明，日海智能因商誉减值金额核算错误、重大融资成分项目核算错误等，2018年、2019年分别虚增利润3,343.32万元、368.29万元，分别占其当年披露利润总额的37.58%、5.13%，相关年度报告存在虚假记载。日海智能2020年非公开发行文件引用了上述年报财务数据，立信所出具专项核查回复及《审计机构声明》。

## 违法事实

立信所未勤勉尽责，出具存在虚假记载的审计报告及非公开发行相关文件。一是商誉审计程序执行不到位：2018年审计中对子公司龙尚科技商誉减值测试直接引用评估机构报告，未复核含少数股东权益的商誉影响；2019年仍未发现商誉计算错误，非公开发行核查中仍直接引用评估报告计算过程，未独立核查。二是主营业务收入审计程序执行不到位：对全资孙公司重大融资成分项目未充分关注复核，未发现收入多确认213.12万元。立信所行为违反《证券法》关于证券服务机构勤勉尽责的规定。

## 处罚依据

深圳证监局认定，立信所违反《证券法》第十九条第二款、第一百六十条第一款、第一百六十三条，构成《证券法》第二百一十三条第三款所述"未勤勉尽责，所制作、出具的文件有虚假记载"行为，签字注册会计师张勇、王泽晖为直接负责的主管人员。

## 处罚结果

深圳证监局出具《行政处罚决定书》〔2024〕30号（2024年12月31日）：对立信会计师事务所（特殊普通合伙）责令改正，没收业务收入3,773,584.92元，并处以7,547,169.84元罚款（合计罚没约1132万元）；对张勇给予警告并罚款55万元；对王泽晖给予警告并罚款50万元。

## 要点分析

会计师事务所从事证券服务业务，对出具的审计报告及为证券发行出具的相关文件，均对真实性、准确性、完整性承担法定保证义务，该义务不因文件名称、形式不同而被豁免。商誉减值、重大融资成分等涉及重大会计估计的领域，审计师须独立计算与复核，不能简单依赖管理层或评估机构结论，否则将面临"没一罚二"量级的行政处罚。
