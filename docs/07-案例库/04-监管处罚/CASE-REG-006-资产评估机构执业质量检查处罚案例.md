# 资产评估机构执业质量检查处罚案例

## 案情概述

为加强对资产评估行业的联合监管，财政部监督评价局会同中国资产评估协会，依据《中华人民共和国资产评估法》对备案从事证券服务业务的资产评估机构开展执业质量检查。2024年度检查的15家机构中，依法对5家评估机构、14名资产评估师、1位评估机构法定代表人作出行政处罚。佳信拓投（江西）房地产资产评估有限公司（以下简称"佳信拓投"）是其中情节最为严重的典型案例。

## 违法事实

经查，佳信拓投共有347份资产评估报告涉及冒签（由非签字评估师或其他人员代签）；其出具的某冒签的公允价值资产评估报告，存在直接以预先设定的价值作为公路资产评估结论、伪造证明材料等问题。此外，佳信拓投在接受执业质量检查期间，两次采取伪造发文登记本的方式故意不报、瞒报资产评估报告309份；出具的某公司股东全部权益价值资产评估报告存在容积率选择错误等问题。

## 处罚依据

财政部依据《中华人民共和国资产评估法》关于评估机构及评估师执业规范、法律责任的规定，结合违法事实的性质与社会危害程度作出处罚。

## 处罚结果

财政部给予佳信拓投警告、责令停业一年、没收违法所得并处罚款合计1566.47万元的行政处罚。同时，中国资产评估协会依据《中国资产评估协会会员执业行为自律惩戒办法》，给予佳信拓投公开谴责的自律惩戒，给予签字资产评估师王林燕、唐泽雄严重警告的自律惩戒。

## 要点分析

评估报告是资本市场信息披露的核心文件，其质量关系定价效率与市场信任。冒签、预设评估结论、伪造证明材料、瞒报报告等行为严重破坏评估独立性、客观性原则，是监管"零容忍"的重点。评估机构应健全内部治理与质控复核，评估师须对签署的报告实质承办、勤勉尽责，否则将面临资格罚与财产罚并重的法律后果。
