# 企业破产重整财务顾问案例

## 案情概述

青海盐湖工业股份有限公司（盐湖股份，000792）拥有察尔汗盐湖开采权，是我国钾肥工业基地。因盲目扩张金属镁一体化等项目持续巨额亏损，2019年度以458.6亿元亏损成为A股"亏损之王"，总负债近500亿元，2020年5月暂停上市，地区性重大金融风险一触即发。2019年9月30日，西宁中院裁定受理盐湖股份破产重整；2020年1月20日裁定批准重整计划。中国国际金融股份有限公司（中金公司）担任财务顾问，协助设计市场化、法治化重整方案。

## 咨询过程（方案要点）

财务顾问协助确定的核心思路是：以市场化方式剥离亏损资产、调整资产和业务结构，全面实施以去杠杆为目标的债务重组，而非依赖国有股东"堵窟窿"式救助。具体分三步：第一步剥离资产，将盐湖镁业、海纳化工及化工分公司剥离出上市公司，止住"出血点"并收回现金对价；第二步权益调整，按每10股转增9.5股实施资本公积转增股本，转增股票用于抵偿债务及由资产承接方有偿受让；第三步分类清偿债务，对有财产担保债权留债清偿、职工债权与税款债权现金全额清偿、普通债权由债权人选择留债或债转股（转股价13.1元/股）。

## 处理结果

重整后盐湖股份总负债由逾500亿元压降至约148亿元，资产负债率降至70%左右，财务费用大幅下降。剥离失血资产后保留钾肥与碳酸锂两大核心业务。2021年8月10日，盐湖股份恢复上市，总市值一度突破2000亿元，成为防范化解重大风险、支持西部发展的标杆型重整项目。

## 要点分析

上市公司破产重整财务顾问的价值，在于识别企业是否具备"挽救价值与再生可能"、挖掘投资价值并落地债转股，在债权人、股东、职工、政府多方间平衡利益。本案以"资产剥离＋资本公积转增＋分类偿债"组合，实现了核心资产价值再发现与多方共赢，是市场化、法治化重整的典范。
