# 税务筹划咨询案例

## 案情概述

A公司系一家港股上市公司，其控股股东为北京市国资委直属企业B集团公司。为完善国资管理、置换优质资源，A公司拟向B集团公司置出C公司（A股上市公司）的母公司D公司的股权，并置入B集团公司旗下E公司的股权。A公司原计划分"两步走"：先由A公司与B集团公司进行股权置换，再由B集团公司吸收合并D公司，以实现压缩企业层级、直接持有C公司股份的目的。

## 咨询方案与过程

律师及税务顾问团队在交易架构设计环节，并未机械执行"股权置换＋吸收合并"的两步走指令，而是从客户需求出发重新设计：将"资产置换＋吸收合并"合并为"吸收合并同时资产置换"的一步走方案——由B集团公司直接吸收合并D公司，并以所持E公司股权作为合并对价支付给A公司，差额以现金补齐。

该方案的关键税务考量是适用企业重组特殊性税务处理。根据《财政部、国家税务总局关于企业重组业务企业所得税处理若干问题的通知》（财税〔2009〕59号），同一控制下且股权支付金额不低于交易支付总额85%的企业合并，可选择特殊性税务处理：合并企业接受被合并企业资产负债的计税基础以原计税基础确定，被合并企业股东取得合并企业股权的计税基础以其原持有股权计税基础确定，无需进行所得税清算。相比两步走方案需等待12个月方可吸收合并，一步走方案同时满足股权置换与压缩层级目的。

## 处理结果

A公司采纳优化方案，项目总标的额近40亿元人民币，不仅适用特殊性税务重组节税数亿元，还节省了超过1年的重组时间，获得客户好评。

## 要点分析

税务筹划咨询的核心在于"商业实质真实、交易架构合规"。本案通过灵活运用同一控制下吸收合并并以股权作为合并对价的少见架构，将一般性税务处理转化为特殊性税务处理，在合法框架下实现节税与时效双重目标。咨询机构应严守独立交易原则与合理商业目的，完整留存商业目的证明、资产评估报告与完税凭证等证据链，避免触及避税红线。
