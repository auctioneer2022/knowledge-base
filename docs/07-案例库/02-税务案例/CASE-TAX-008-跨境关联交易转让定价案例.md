# 跨境关联交易转让定价案例

## 案情概述

丰田秘鲁股份有限公司（Toyota Perú，丰田集团子公司）主要负责在秘鲁销售丰田汽车及零部件。秘鲁税务局对其2009年度关联交易开展转让定价调查，重点调查丰田秘鲁当年从境外关联方进口皮革座椅、空调等汽车零部件及汽车整车的交易定价。调查发现，丰田秘鲁2009年度利润率仅为-0.98%，秘鲁税务局据此提出质疑，认为其关联交易定价不合理。

## 税务处理

丰田秘鲁向税务局提交转让定价研究报告，对比分析了6家可比公司2007—2009年财务数据，认为2009年利润率符合独立交易原则。但秘鲁税务局仅采用报告中2009年单一年度数据，认定丰田秘鲁-0.98%的利润率显著低于可比公司利润率四分位区间下限3.24%，据此于2017年发出税务调整通知，要求丰田秘鲁补缴约4500万秘鲁索尔（约合7900万元人民币）税款及利息。

丰田秘鲁不服，起诉至法院。争议焦点有二：一是转让定价分析应采用"单一年度数据"还是"多年期数据"；二是税务局能否在纳税人提供的可比性分析基础上进行"挑选式"调整。丰田秘鲁主张2009年正值全球金融危机后经济下行，应依OECD转让定价指南采用多年期数据消除异常影响。

## 处理结果

秘鲁最高法院发布终审判决，丰田秘鲁胜诉。法院认可转让定价分析应连贯、一致，单一年度亏损不能单独作为定价不合理的依据，税务机关"挑选式"采用数据缺乏合理性。最终撤销了税务调整决定。

## 要点分析

本案与典型的境内关联交易调整（如关联企业间低价转让股权、服务费分摊）不同，属于跨境母子公司的有形资产关联交易转让定价争议。其启示是：转让定价方法的应用须注重时效性与动态性，应优先采用多年期数据以消除偶然因素扭曲；"走出去"企业在海外经营应备存充分的可比性分析资料，以在反避税调查中有效抗辩。
