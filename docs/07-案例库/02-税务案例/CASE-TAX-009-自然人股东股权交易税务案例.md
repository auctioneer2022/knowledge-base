# 自然人股东股权交易税务案例

## 案情概述

2023年，福建省三明市泰宁县某公司原控股股东王元春、王逢春在转让该公司股权过程中，通过签订"阴阳合同"等方式隐匿真实收入、进行虚假纳税申报。税务稽查部门根据外部门移交线索立案检查，发现该公司在已完成股权变更手续的情况下，仍多次为原股东代垫个人所得税，不符合常理。

## 税务处理（违规事实）

检查人员比对纳税申报数据与财务报表，发现王元春、王逢春经自查补缴税款后对应的股权转让收入为1398万元，高于协议载明的1300万元。进一步取得双方实际履行协议后，确认真实交易金额为2600万元。资金流水显示，王元春、王逢春陆续收到受让方转入资金3050万元，远超协议约定，其中1750万元未备注用途（1300万元为未申报股权款，450万元为承接的债权债务结算款）。以上表明，出让方通过"阴阳合同"隐匿股权转让收入，少缴个人所得税等税款。

## 处理结果

2025年6月，国家税务总局三明市税务局稽查局依法对该偷税行为作出处理处罚决定：追缴税款、加收滞纳金并处罚款共计524.38万元（其中少缴个人所得税等税款298.29万元）。目前涉案税款、滞纳金及罚款均已追缴入库。

## 要点分析

自然人股东转让股权，依《股权转让所得个人所得税管理办法（试行）》（国家税务总局公告2014年第67号）以"财产转让所得"适用20%税率，由受让方扣缴、转让方申报。本案中"阴阳合同"、代垫税款、资金流水与协议不符等，均为税务机关识别隐匿收入的典型线索。自然人股东应如实申报股权转让收入，低价或无偿转让须符合67号文明示的正当理由，否则税务机关有权按净资产核定法、类比法核定收入并追征税款及滞纳金、罚款。
